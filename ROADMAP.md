# Project roadmap (initial)

## Milestones
- v0.1 — Skeleton & notes scaffold  
- v0.2 — Presburger core (sets, constraints, basic ops)  
- v0.3 — Polyhedral representation (domains, access relations)  
- v0.4 — Dependence analysis (dependence polyhedra)  
- v0.5 — Scheduling (Feautrier/Pluto-style)  
- v0.6 — Codegen (loop reconstruction)  
- v0.7 — Visualization & examples  

## Chapter ↔ tasks
- **Ch.1 Presburger**: implement linear constraint system, union/intersection, projection (Fourier–Motzkin or ILP).  
- **Ch.2 Polyhedral model**: iteration domain, access function, relation composition.  
- **Ch.3 Dependence**: build dependence graph, compute dependence polyhedra.  
- **Ch.4 Scheduling**: single-dim and multi-dim affine schedules via ILP.  
- **Ch.5 Codegen**: generate affine loops from schedules.  

> This roadmap is living and will evolve with the reading pace.
